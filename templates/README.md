# 资料包导入模板

`资料包导入模板.csv` 用于把地点批量导入「旅游AA账本」的 📍 地点库。

## 使用方法
1. 用 Excel / Numbers / WPS 打开 `资料包导入模板.csv`（第一行是列名，后面两行是示例，可删除）。
2. 每行填写一个地点，**只有「名称」必填**，其余可留空。
3. 保存为 CSV（UTF-8 或 Excel 默认的 GBK 编码都可以）。
4. 在网页「地点 → 📥 导入」中选择文件，填写资料包名称后导入。

## 列说明
| 列 | 填写方式 |
|---|---|
| 名称 | 必填 |
| 类型 | 景点 / 餐厅 / 住宿 / 购物 / 交通 / 活动 / 其他（也识别「酒店」「美食」「门票」） |
| 状态 | 去过 / 想去；留空时按导入窗口中的默认值 |
| 国家/地区、城市、地址、官网、电话、营业时间 | 文字 |
| 评分 | 1–5 的整数 |
| 人均花费 | 数字（按基准币种理解） |
| 标签 | 多个用 `/` 分隔，如 `世界遗产/适合拍照` |
| 印象、体验项目、特色内容、备注 | 文字 |
| 厕所 | 干净 / 一般 / 较差 / 没有 / 未知 |
| 无障碍 | 友好 / 部分可行 / 不便 / 未知 |
| 厕所说明、无障碍说明 | 文字 |
| 到访日期 | `YYYY-MM-DD` 或 `YYYY/MM/DD` |
| 纬度、经度 | 可选，数字 |

同名且同城的地点会合并：只补全原来为空的字段，标签取并集，不会覆盖已有内容。
